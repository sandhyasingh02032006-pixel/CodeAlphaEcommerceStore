# 🛒 CodeAlpha E-Commerce Store

A full-stack E-Commerce Store developed as part of my **CodeAlpha Full Stack Development Internship**.

## 🚀 Features

- User Registration
- User Login & Logout
- Product Listing
- Product Details
- Add to Cart
- Increase/Decrease Product Quantity
- Remove Products from Cart
- Checkout System
- Order Processing
- My Orders Page
- MySQL Database Integration
- Password Hashing using bcryptjs

## 💻 Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- bcryptjs
- REST API

## 📁 Project Structure

- `public/` - Frontend pages and product images
- `server.js` - Express backend server and APIs
- `package.json` - Project dependencies
- `.gitignore` - Files excluded from Git

## ⚙️ How to Run

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Create a MySQL database.
4. Configure database credentials in a `.env` file.
5. Start the server using `node server.js`.
6. Open `http://localhost:5000/products.html` in your browser.

## 🔐 Security

User passwords are securely hashed using **bcryptjs** and sensitive environment variables are stored in `.env`, which is excluded from GitHub.
